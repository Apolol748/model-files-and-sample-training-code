## Model Runs and Training Code

All model runs and their corresponding metrics are stored in the `runs/` folder.

The repository also includes sample training code. You can use it to:

- **Reproduce the training process** using the provided configurations.
- **Evaluate trained models** by directly loading the PyTorch files from the model runs.
- **Modify the code** to experiment with different configurations or create your own implementations.

Feel free to explore and adapt the code for your own experiments!
